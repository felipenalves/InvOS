# Proposta avançada (opcional)

Use **só** se o user pedir proposta enterprise, RFP, orçamento formal longo, tiers, ROI e T&C completos.

Fluxo resumido (ainda em PT-BR; sem reinventar a empresa — leia `memoria/` e `clientes/` antes):

1. **Contexto do deal** — contato, dor com número se houver, budget, prazo, concorrência  
2. **Resumo executivo** — problema → por que agora → solução → investimento → CTA  
3. **Escopo** — fases, entregáveis, **fora de escopo**, critério de aceite  
4. **Preço** — 1–3 opções se fizer sentido; “custo de não fazer” se tiver dado  
5. **Prova** — só cases/ credenciais que existirem na memória ou que o user der  
6. **T&C curtos** — pagamento, prazo, cancelamento, o que é do cliente  
7. **Checklist pré-envio** + 1 follow-up D+3  

Grave em `clientes/<slug>/propostas/YYYY-MM-DD-completa.md`.

Se o user for prestador solo com deal simples, **volte** para a skill slim (`SKILL.md`) — proposta curta fecha mais.
